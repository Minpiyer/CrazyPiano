## Current home page review

- The Hero uses an adult-only teacher image.
- The About section uses a different teacher-and-student image and therefore requires guardian or rights-holder permission before public launch.
- Every Student Recital Gallery image contains at least one minor and requires confirmed public-use permission.
- No student names should appear anywhere on the public website.
- If permission cannot be confirmed, replace the image with an adult-only teacher portrait, a hands-at-the-keyboard detail, an empty recital-stage photograph, or another image with documented usage rights.
